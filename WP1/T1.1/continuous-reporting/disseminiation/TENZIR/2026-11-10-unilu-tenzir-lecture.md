- **Status:** Delivered

## Target audience reached

## Objective

using NGSOTI's Tenzir training module.

## Project output

The lecture drew on [Module 8: Security data pipelines and detection engineering
with Tenzir](../../../../../training/tenzir/README.md). It covered collecting and
normalizing security telemetry, correlating events from multiple sensors, and
using threat intelligence and detection rules to investigate an incident.
