# Communication activity: Tenzir's Kunai integration page

## Description

Tenzir published a [Kunai integration page](https://tenzir.com/product/integrations/kunai/)
in October 2026. It explains how to use Kunai Linux telemetry with Tenzir and
normalize it to the Open Cybersecurity Schema Framework (OCSF). The integration
is part of the NGSOTI training SOC and its
[Tenzir training module](../../../../../training/tenzir/README.md).
